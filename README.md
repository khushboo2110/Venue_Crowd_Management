# Venue Crowd Management

An AI-powered web application that helps event organizers predict crowd congestion, identify bottlenecks, and suggest alternate routes for smooth crowd movement inside venues such as stadiums, concerts, exhibitions, and festivals.

## 🚀 Features

- 🗺️ Interactive venue layout
- 📍 Crowd density visualization
- 🤖 AI-based congestion prediction
- 🔀 Dynamic alternate route suggestions
- 📊 Dashboard with crowd analytics
- 📈 Risk percentage calculation
- 📍 Bottleneck detection
- ⚡ Real-time monitoring interface
- 📱 Responsive UI

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/khushboo2110/Venue_Crowd_Management.git
```

Move into project folder

```bash
cd Venue_Crowd_Management
```

---

### Install Frontend

```bash
cd client
npm install
```

### Install Backend

```bash
cd ../server
npm install
```

---

## ▶️ Run the Project

### Start Backend

```bash
cd server
npm start
```

### Start Frontend

```bash
cd client
npm run dev
```

## 🤖 AI Integration

This project uses the **Hugging Face Inference API** to:

- Analyze crowd conditions
- Predict congestion levels
- Estimate risk percentage
- Recommend alternate movement paths
